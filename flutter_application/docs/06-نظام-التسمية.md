# 06 — نظام التسمية الموحد (Naming Conventions)

**تاريخ الإنشاء:** 2026-09-25  
**آخر تعديل:** 2026-09-25  
**الحالة:** معتمد

---

## المبدأ الأساسي

> الاسم الجيد هو اسم **يصف وظيفته بوضوح دون الحاجة لقراءة الكود**.

قواعد التسمية ليست اختياراً جمالياً — هي اتفاق يُمكّن الفريق من قراءة الكود وفهمه بشكل موحد.

## 1. أسماء المجلدات

**الصيغة:** `snake_case` (حروف صغيرة مفصولة بـ `_`)

```
lib/
├── core/
│   ├── constants/
│   ├── theme/
│   ├── router/
│   ├── widgets/
│   └── responsive/
└── features/
    ├── onboarding/
    │   └── presentation/
    │       └── screens/
    ├── auth/
    └── home/
```

**قواعد:**
- حروف صغيرة دائماً.
- كلمات مفصولة بـ `_`.
- لا مسافات، لا حروف كبيرة، لا `camelCase` في المجلدات.
- أسماء تعبر عن المحتوى (وظيفي / تقني)، لا عن التقنية المستخدمة فيه.

## 4. Widgets

**قاعدة التمييز بين Screen وWidget:**

| النوع | متى يُستخدم | مثال |
|---|---|---|
| **Screen** | الشاشة الكاملة التي لها Route | `SplashScreen`، `OnboardingScreen` |
| **Page** | شاشة كاملة في تطبيقات كبيرة | `DriverHomePage` |
| **Widget** | مكوّن قابل لإعادة الاستخدام | `HamulaButton`، `StatusBadge` |

**قواعد Widgets:**
- كل Widget عام (مشترك بين شاشات) يُوضع في `core/widgets/`.
- كل Widget خاص بميزة يُوضع داخل مجلد الميزة.
- أسماء Widgets تبدأ بـ `Hamula` للمكوّنات العامة: `HamulaButton`، `HamulaTextField`، `HamulaAppBar`.

## 5. BLoC وCubit

```dart
// BLoC
class AuthBloc extends Bloc<AuthEvent, AuthState> { }

// الـEvents
abstract class AuthEvent extends Equatable { }
class LoginRequested extends AuthEvent { }
class LogoutRequested extends AuthEvent { }

// الـStates
abstract class AuthState extends Equatable { }
class AuthInitial extends AuthState { }
class AuthLoading extends AuthState { }
class AuthAuthenticated extends AuthState { }
class AuthUnauthenticated extends AuthState { }
class AuthError extends AuthState { }

// Cubit (للحالات الأبسط)
class ThemeCubit extends Cubit<ThemeState> { }
```

**قواعد:**
- BLoC للحالات المعقدة التي لها Events متعددة.
- Cubit للحالات البسيطة التي لا تحتاج Events.
- كل BLoC/Cubit في مجلد الميزة الخاصة به: `features/auth/bloc/`.

## 6. المتغيرات والدوال (Variables & Functions)

**الصيغة:** `camelCase` لكل المتغيرات والدوال والـParameters.

```dart
// متغيرات
String userName;
bool isLoading;
int shipmentCount;

// دوال
void loadUserProfile() { }

// Booleans — تبدأ بـ is أو has أو can

bool canViewDetails;

// Constants — SCREAMING_SNAKE_CASE
const String kApiBaseUrl = 'https://api.hamoola.com';

```

## 7. API Endpoints

**الصيغة:** `kebab-case` مع `nouns` وليس `verbs`، واستخدام HTTP Method للتعبير عن الفعل.

```
// صيغة عامة
/api/v1/{resource}
/api/v1/{resource}/{id}
/api/v1/{resource}/{id}/{sub-resource}

// أمثلة
GET    /api/v1/users
GET    /api/v1/users/{id}
POST   /api/v1/users
PUT    /api/v1/users/{id}
DELETE /api/v1/users/{id}

GET    /api/v1/shipments
POST   /api/v1/shipments
GET    /api/v1/shipments/{id}
GET    /api/v1/users/{id}/shipments

POST   /api/v1/auth/login
POST   /api/v1/auth/logout
POST   /api/v1/auth/refresh-token
```

**قواعد:**
- حروف صغيرة دائماً.
- كلمات مفصولة بـ `-` (kebab-case).
- الجمع (plural) للـResources: `/users` لا `/user`.
- لا أفعال في الـURL: ❌ `/getUsers`، ✅ `GET /users`.
- Versioning في الـURL: `/api/v1/`.

## 8. جداول قاعدة البيانات (Database Tables)

**الصيغة:** `PascalCase` للـEntity، `snake_case` للجداول (حسب Convention المستخدم في EF Core).

| النوع | الصيغة | مثال |
|---|---|---|
| اسم الجدول | `PascalCase` (Plural) | `Users`، `Shipments`، `Drivers` |
| اسم حقل Primary Key | `Id` | `Id` |
| اسم حقل Foreign Key | `{TableName}Id` | `UserId`، `ShipmentId` |

```sql
-- أمثلة
Users           (Id, FullName, PhoneNumber, Role, CreatedAt)
Shipments       (Id, TraderId, DriverId, OfficeId, Status, CreatedAt)
Drivers         (Id, UserId, LicenseNumber, VehicleId)
Vehicles        (Id, PlateNumber, VehicleType, Capacity)
```

## 9. أعمدة قاعدة البيانات (Database Columns)

**الصيغة:** `PascalCase`

```sql
-- أمثلة
Id              -- Primary Key دائماً
FullName
PhoneNumber
EmailAddress
CreatedAt       -- Timestamps دائماً بـAt
UpdatedAt
DeletedAt       -- للـSoft Delete
IsActive        -- Booleans تبدأ بـIs
HasVerified
```

**قواعد:**
- `CreatedAt`, `UpdatedAt`, `DeletedAt` — لكل جدول.
- `IsDeleted` أو `DeletedAt` للـSoft Delete.
- لا اختصارات غامضة: ❌ `PNum`، ✅ `PhoneNumber`.
